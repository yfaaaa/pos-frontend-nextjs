# 🛒 POS Frontend Next.js (Kasir Warungku)

Aplikasi kasir (Point of Sale) modern berbasis web, dirancang untuk UMKM atau warung. Proyek ini saat ini berfokus pada **UI/UX Frontend** dengan fitur keranjang belanja interaktif.

## ✨ Fitur Tersedia
- **Katalog Produk:** Grid produk responsif dengan gambar dan harga.
- **Live Search:** Pencarian barang secara *real-time* tanpa *reload*.
- **State Management Keranjang:** Tambah/kurang/hapus barang di keranjang menggunakan Zustand.
- **Validasi Stok:** Tombol otomatis nonaktif (habis) jika stok mencapai 0.
- **Animasi UI:** Efek *hover*, transisi halus, dan animasi peringatan menggunakan Tailwind CSS.

## 🛠️ Tech Stack
- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **State Management:** [Zustand](https://github.com/pmndrs/zustand)
- **Icons:** [Lucide React](https://lucide.dev/)
